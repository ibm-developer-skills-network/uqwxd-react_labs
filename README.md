# IBM React Labs

Hands-on React development exercises completed as part of IBM Developer Skills Network training.

This repository contains practical labs covering React fundamentals, component-based development, and state management with Redux.

## 📚 Labs

### Hello World

A basic React exercise focused on getting familiar with the React application structure and development environment.

### Todo List

A practical React application used to practice building components and managing application functionality.

### React Redux

A hands-on Redux exercise demonstrating centralized state management in a React application.

The exercise implements an increment counter using:

- React components
- Redux
- React Redux
- Actions
- Reducers
- Store
- `Provider`
- `useDispatch`
- `useSelector`
